##### What you will do

- Design, develop, debug, and maintain MCU firmware, including low-level drivers, peripheral interfaces, control logic, and system features.
- Develop drivers and run hardware/software integration for sensors, motors, actuators, and communication modules.
- Develop and debug common MCU peripherals such as UART, I²C, SPI, CAN, PWM, ADC, Timer, and DMA.
- Bring up new hardware platforms and validate functionality using schematics, chip datasheets, and reference manuals.
- Use oscilloscopes, logic analyzers, and related tools to isolate communication, timing, signal-integrity, and hardware/software issues.
- Take part in system integration, prototype debugging, and performance tuning for motor, sensor, and robotics modules.
- Write test programs and, where useful, automated test tools, documenting issues, results, and resolutions.
- Collaborate with hardware, mechanical, and application-software teams on feature validation, issue isolation, and version iterations.

- Bachelor's degree or above in electronics, automation, computer science, mechatronics, communications, or a related field.
- Solid C fundamentals and a grasp of core embedded software practices.
- Hands-on MCU project experience, able to independently handle peripheral setup, driver development, and system debugging.

- Able to read schematics and configure peripherals and write drivers from datasheets and reference manuals, rather than relying only on existing libraries or sample code.

- Understand interrupts, DMA, memory, boot flow, linking, and basic MCU system architecture.
- Basic RTOS experience, understanding tasks, scheduling, synchronization, mutexes, and message queues.

- Familiar with embedded toolchains such as Git, CMake, GCC / Clang, and GDB / OpenOCD.
